# Personal Portfolio Website

An interactive, responsive personal portfolio web application designed to showcase professional work, technical skills, verified certifications, and personal achievements.

---

## 📌 Project Overview

This portfolio website serves as a dynamic, interactive digital hub to highlight professional projects, skills, certifications, and background. Rather than relying on a traditional static resume, this platform delivers an engaging user experience with real-time theme customization, interactive media showcases, and structured accomplishment tracking.

---

## 🛠️ Full Technology Stack

* **Frontend Framework**: React 18 (built with Vite for high-performance bundling)
* **Styling & UI**: Tailwind CSS, Custom CSS/SCSS, Lucide Icons, Framer Motion
* **Backend Runtime**: Node.js & Express (API integration and server routing)
* **Hosting & Deployment**: Vercel
* **Tools & Automation**: Git, GitHub, Google AI Studio
* **Libraries & APIs**: Lucide React, Axios

---

## 💡 Problems It Solves

* **Centralized Portfolio**: Provides a single, professional destination to view projects, credentials, and achievements.
* **Interactive Resume**: Transforms standard static CVs into an engaging, interactive digital experience with live previews and filters.
* **Dynamic Content Display**: Solves the limitation of PDF resumes by allowing rich media galleries and verified credential viewing.
* **Demonstrates Engineering Competency**: Highlights full-stack development expertise, responsive UI craftsmanship, and real-world deployment practices.

---

## ✨ Features

* **Responsive Design**: Flawlessly optimized across all screen sizes (desktop, tablet, mobile).
* **Dark / Light Theme Toggle**: Seamless appearance switching with persistent user preferences.
* **Verified Credentials & Certificates**: Showcase section featuring authentic industry certificates from **Deloitte**, **Goldman Sachs**, **Tata Group**, and more.
* **Image & Work Gallery**: Clean, high-performance visual gallery showcasing uploaded photos, projects, and milestones.
* **Interactive Contact & Social Links**: Built-in contact form and direct links to LinkedIn, GitHub, and professional networks.

## ⚙️ Installation & Usage

### Prerequisites
* **Node.js**: v18.0.0 or higher
* **npm**: v9.0.0 or higher

### Steps to Run Locally

1. **Clone the Repository**
   ```bash
   git clone <repo-url>
   cd <repo-folder>
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```

4. **Build for Production**
   ```bash
   npm run build
   ```

---

## 🚀 Deployment Info

This application is configured for deployment on **Vercel** with continuous integration via GitHub.

To deploy using the Vercel CLI:
```bash
vercel deploy
```

For production deployment:
```bash
vercel --prod
```
